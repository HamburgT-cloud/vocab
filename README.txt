単語トレーナー（オフライン対応）

■ すぐ使う
  index.html をダブルクリック（ブラウザで開く）。通信は一切使いません。
  学習記録と「箱」は、そのブラウザの中に保存されます。

■ 自分の問題集にする（Excel）
  words.csv をExcelで開き、word / pos / meaning を編集して「CSV UTF-8」で保存。
  アプリの「データの管理」から取り込みます。
  pos は n（名詞）v（動詞）adj（形容詞）adv（副詞）。空欄でも動きます。

■ GitHub Pagesで公開してスマホでも使う
  1) GitHubで新しいリポジトリを作る
  2) このフォルダ内の index.html / sw.js / manifest.webmanifest / icon.svg / words.csv をアップロード
  3) Settings > Pages で、公開元を main ブランチにする
  4) 表示されたURLをスマホで開き、一度読み込めば、その後は圏外でも使えます
     （iPhoneは共有ボタン > ホーム画面に追加）
  ※記録は端末ごとに別々です。
